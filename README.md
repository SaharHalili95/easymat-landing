# EasyMat Landing Page

Landing page for [EasyMat](https://github.com/SaharHalili95/easymat), an AI math tutor for the Israeli Bagrut exam (3, 4 and 5 units).

**Live:** https://saharhalili95.github.io/easymat-landing/

A single static `index.html` in Hebrew (RTL) with the Heebo font. No build step: open the file in a browser or serve the folder with any static server.

```bash
python3 -m http.server 8000
```
